Bookmarks But Better is a bookmark manager that turns your new tab into the bookmarks you already have, with every folder as a card. It can also be set as your Firefox homepage.

Install it and it works. There is no account to create and nothing to configure first. Open a new tab and your folders are there in a responsive masonry layout, with a search palette and a full drag-and-drop organizer, instead of digging through browser menus.

No advertising, no analytics, no tracking. Everything past that is optional and every part of it is free and open source, including a local daemon that keeps your bookmarks as plain Markdown files in a folder you own.

FEATURES

- Full Bookmark Organizer tree editor
- Search palette: start typing anywhere on the dashboard to find a bookmark by title or URL
- Quick capture: save the page you are on from the toolbar popup
- Drag bookmarks between folders and reorder them
- Create, rename and delete bookmarks and folders
- List and icon-grid views per folder
- Choose any folder as the dashboard root
- Ten color themes plus light, dark and system modes
- High-quality favicons with a clean letter fallback

- Address-bar search with the “bb” keyword
- Standard HTML import and export, plus CSV import from Raindrop and Pocket
- Safe mode, and a Settings page reachable from the browser's add-ons page, for a new tab that will not load

UPGRADING

Version 4 upgrades in place. Existing users keep their root folder, layouts, themes and completed setup state. The setup wizard is shown again only when requested from Settings. The legacy standalone collection keeps working and can be copied into a vault; the copy leaves the original intact.

PRIVACY

Bookmarks But Better has no account system, analytics, tracking, ads or bookmark-content collection. Browser mode reads and updates bookmarks through Firefox's built-in APIs. Preferences remain local to the browser profile.

Bookmark origins are sent to Google's public favicon service to retrieve icons; URL paths are not sent. Icons are cached on the device. Daemon mode is optional, binds to localhost only and is contacted only after the user explicitly connects it.

PERMISSION JUSTIFICATIONS

activeTab: Reads the active tab's title and URL only when the user opens the extension popup to save that page.

bookmarks: Displays and manages the user's Firefox bookmark tree.

storage: Saves local preferences, the selected root folder and completed setup state.

HOST PERMISSIONS

https://t1.gstatic.com/*: Google Favicon V2 provider.

OPTIONAL HOST PERMISSIONS

http://127.0.0.1/* and http://localhost/*: Requested only when the user connects the extension to their optional local daemon. They are not granted during installation.
