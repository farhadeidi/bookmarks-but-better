Bookmarks But Better replaces your new tab page with a clean, organized dashboard for the bookmarks you already have. It can also be set as your Firefox homepage.

Open a new tab and see your folders in a responsive masonry layout instead of digging through browser menus.

Install it and it works. There is no account to create and nothing to configure first: the dashboard shows the bookmarks this browser already has. There is no advertising, no analytics and no tracking. Everything past that is optional, and every part of it is free and open source.

WHAT'S NEW IN VERSION 4

- Use your browser bookmarks, a local Markdown vault, or both, and switch between them from the top of the dashboard
- A guided setup that asks which sources to use and walks you through connecting a vault, or lets you skip straight to your bookmarks
- Set up the optional vault daemon with one command: npx bookmarks-but-better@latest
- Choose the dashboard's root folder right from the new tab
- Search your bookmarks from the address bar: type “bb”, press Tab, then search by title or URL
- Save the active page to your bookmarks from the extension popup
- Import and export standard browser bookmark HTML files, plus CSV import from Raindrop and Pocket
- Site icons cached on your device, so each site's icon is fetched about once a month
- Safe mode, and a Settings page you can open from the add-ons page, for a new tab that will not load
- Upgrades keep your completed setup and existing preferences

UPGRADING

Version 4 upgrades in place. Existing users keep their root folder, layouts, themes and completed setup state. The setup wizard is shown again only when requested from Settings. The legacy standalone collection keeps working and can be copied into a vault; the copy leaves the original intact.

PRIVACY

Bookmarks But Better has no account system, analytics, tracking, ads or bookmark-content collection. Browser mode reads and updates bookmarks through Firefox's built-in APIs. Preferences remain local to the browser profile.

Bookmark origins are sent to Google's public favicon service to retrieve icons; URL paths are not sent. Icons are cached on the device. Daemon mode is optional, binds to localhost only and is contacted only after the user explicitly connects it.

PERMISSION JUSTIFICATIONS

activeTab: Reads the active tab's title and URL only when the user opens the extension popup to save that page.

bookmarks: Displays and manages the user's Firefox bookmark tree.

storage: Saves local preferences, the selected root folder and completed setup state.

HOST PERMISSIONS

https://t1.gstatic.com/*: Google Favicon V2 provider.

OPTIONAL HOST PERMISSIONS

http://127.0.0.1/* and http://localhost/*: Requested only when the user connects the extension to their optional local daemon. They are not granted during installation.
