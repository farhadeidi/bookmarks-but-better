Then set up where your bookmarks live

Safari does not share its own bookmarks with extensions — this one never reads or changes them. Your bookmarks live in a folder of Markdown files on this Mac, served by a small local program called the daemon. Put that folder in iCloud Drive and every Mac you use sees the same bookmarks.

  1. Install the daemon. In Terminal:

    curl -fsSL https://github.com/farhadeidi/bookmarks-but-better/releases/latest/download/install.sh | bash

  2. Create your vault and start it at login:

    bookmarks-but-better setup

    It asks a few questions, then keeps running on its own.

  3. Back in Safari, click the Bookmarks But Better icon in the toolbar and choose Open the dashboard, then Connect a daemon. Safari asks permission for 127.0.0.1 at that moment — that is the only network access this extension ever requests.

The commands above can be selected and copied.
